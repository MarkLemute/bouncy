# Bouncy

A simple paddle-and-ball game built with Python and Pygame.

Keep the ball in play with your paddle. Every hit scores a point and makes the ball a little faster. Where the ball lands on the paddle changes its angle.

## How to play

```bash
pip install -r requirements.txt
python bouncy.py
```

## Controls

| Key | Action |
| --- | --- |
| Left / Right arrows | Move paddle |
| Space | Restart after game over |
| Esc | Quit |
